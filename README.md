# INDEX — портфолио проектов

Откройте `index.html` в браузере. Сборка, зависимости и интернет для интерфейса не требуются. Ссылки Google Play открываются отдельно.

Для локального предпросмотра через HTTP: `node preview.mjs`, затем http://127.0.0.1:4175.

На сайте три игры — **Solitaire Harmony**, **Squirrel Defender** и **Fractal Puzzle**. Одна страница показывает один кейс. Каждый проект имеет собственную ссылку с `#project/…`.

- Свайп на первом экране Solitaire Harmony или по главному визуалу остальных кейсов — переключить проект.
- Стрелки клавиатуры, кнопки и нижняя панель — альтернативная навигация.
- Вертикальная прокрутка — подробности текущего кейса.
- «Все проекты» — каталог.
- «Логика страницы» — объяснение блокаута.
- Нажатие на скриншот или «Рассмотреть» — увеличить изображение.

Структура: главный экран → контекст и вклад команды → решения с визуалами → подтверждение результата → следующий проект.

Solitaire Harmony находится в отдельной папке `projects/solitaire-harmony/`: `project.js` содержит тексты, разметку и интерактивность, `style.css` — тему, `assets/` — настоящие скриншоты. Подробности в README этой папки. Общая навигация остаётся в корневом `app.js`. Стили темы ограничены атрибутом `data-project` и классами `.sh-*`, поэтому не влияют на другие кейсы.

Проверено в браузере: переключение кейсов и темы, навигация клавишами, каталог, окно логики, выбор режима пасьянса, увеличение скриншота, мобильная компоновка без горизонтального переполнения. Физический свайп на телефоне требует отдельной проверки.

Squirrel Defender — отдельный кейс `projects/squirreldefender/`, маршрут `#project/squirreldefender`. Собственная лесная тема: тёмная зелень, оранжевый и лаймовый акцент, крупная белка, игровой лес, аркадная типографика и интерактивная галерея 7 актуальных авторских скриншотов. Скриншоты доступны в трёх разделах, с выбором миниатюр, стрелками и увеличением. Исходники сохранены в `squirreldefender/`, в кейсе используются WebP без потери качества.

Fractal Puzzle — отдельный кейс `projects/fractal-puzzle/`, маршрут `#project/fractal-puzzle`. Тихая пиксельная бухта: сумеречное море, ступенчатое солнце, квадратный SVG-заголовок, кораблик с повторной сборкой по клеткам и отражения на воде. Ниже — схема правил, три кадра сборки и атлас пяти фигур с увеличением авторских скриншотов. Старый маршрут `#project/form` перенаправляет сюда. После смены визуальной концепции проверен синтаксис JavaScript; визуальную проверку новой версии пользователь выполняет самостоятельно.

Страница автора: `about.html` (стили — `about.css`). Доступна по ссылке «Обо мне» из общей шапки и футера каждого проекта. Содержит краткий профиль, выбранные факты из базы опыта, собственные проекты и контакты. `assets/Roman_Karimov_Resume.pdf` — копия исходного резюме для скачивания; обновлять вместе с master CV.

Обновление «Обо мне»: тёмная авторская тема с лаймовыми акцентами, коллаж из исходного цветного фото автора (`assets/roman-karimov.jpg`) и ассетов трёх игр, полоса фактов и визуальные ссылки на кейсы. В середине страницы — опыт найма: Buddy.ai, игры SayGames с примером Craft Valley, BlueLight и Brainwell. Собственные игры вынесены в следующий раздел. Стили ограничены `.about-page` и `.ab-*`; другие страницы не меняются. Движения учитывают `prefers-reduced-motion`.

Новая тема проверена в браузере на ширинах 320, 390, 768 и 1280 px без горизонтального переполнения. Проверены локальные ссылки на страницы, изображения, стили и PDF.

В футере каждого кейса — отдельная кнопка «Обо мне», переход также доступен в закреплённой нижней панели проектов. В блоке работы в найме добавлены ссылки Buddy.ai и Brainwell, для BlueLight — анонс открытой беты (основной сайт не ответил при проверке). Карусель SayGames содержит 23 подтверждённые игры с локальными официальными иконками, ссылками Google Play и указанием личного вклада. Управление: кнопки, свайп и горизонтальная прокрутка; при фокусе на списке — ←/→, Home/End. На экране одна игра; автолистание каждые 5 секунд, стрелки по бокам и кнопка паузы. При наведении, фокусе клавиатуры, скрытой вкладке и вне видимой области автолистание приостанавливается; при prefers-reduced-motion изначально выключено. `about.js` управляет каруселью; `assets/saygames/games.json` содержит исходные ссылки, `scripts/download-saygames-assets.mjs` обновляет иконки из Google Play. Без JavaScript список остаётся доступен для прокрутки и переходов.

Раздел «Проекты в командах» теперь имеет общий заголовок над пятью широкими строками. В каждой слева — изображение или карусель и внешние ссылки, справа — роль и описание вклада. FinchXR (2015–2022) добавлен последним. На мобильных строки складываются в одну колонку. Для Buddy.ai и My Little Universe добавлены проверенные видео официальных каналов YouTube; источники изображений и видео сохранены в `assets/work/credits.json`.
